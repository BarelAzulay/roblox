My Roblox projects.

## Games

### [Nimbus Climb](nimbus-climb/) — co-op cloud parkour
A cosy cloud-village lobby with match portals, a procedurally generated sky parkour for 1–4 players,
health + damage, revives at checkpoints, and floating cloud tokens to collect.

- **Just want to play it?** Download [`nimbus-climb/play/NimbusClimb.rbxlx`](nimbus-climb/play/NimbusClimb.rbxlx)
  and open it in Roblox Studio, then press **Play**. No other tools needed.
- **Want to edit the code?** See [`nimbus-climb/README.md`](nimbus-climb/README.md) (uses Rojo).
